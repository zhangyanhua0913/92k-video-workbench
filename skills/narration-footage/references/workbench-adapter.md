# 网络素材解说风格：工作台适配 v0.1

从本文件所在Skill根目录读取SKILL.md、references/workflow.md。由Agent运行，不是自动生成服务。输入是工作台当前已确认的旁白时间线及用户稿件，输出为逐段素材/场景方案、可审看的实际片段与来源记录。无配音时不得把搜索当作可自动生成旁白。

主体以真实网络素材为主，结合标题/资料窗/数据/流程；每段查产品准确版本和动作，保存来源/许可状态/原入点/匹配理由。来源或配音预算缺失列缺口，不能继承别项目授权。用scripts/footage.py下载登记/audit，然后按用户确认的方案制作。

在工作台先给scenes计划并审看packaging。每段输出无旁白的包装视频，使用当前项目音轨统一合成，避免重复人声。需要保留外部素材原声的多轨方案不能伪装成当前无声叠层；另存工程与试听混音，再说明支持范围。人物缺席时scene.mode用fullscreen；不可把带字幕/音轨的完整研究片直接attach-scene叠回源片。用工作台原有attach-scene/keyframes/render进行片段导入、确认和导出，遵循已确认项目版本。

样片是单独对比入口，采用前必须按当前稿件重做，不能以样片播放代替该项目制作。不要覆盖原视频或直接改SQLite审批。当前只接Agent制作入口，尚无自动素材候选/选段页面与批次全自动。

版本采用独立注册ID narration-footage-v0-1，升级新版本创建新ID并保留旧ID；原项目继续引用旧版，切换版本由用户选择并重新确认受影响阶段。发布旧版本指令必须保留原路径，不在原路径就地替换后声称原项目锁定。注册前审阅依赖与来源，不能执行清单中的任意shell。
