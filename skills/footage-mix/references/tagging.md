# 逐句打标签（Agent 负责）

脚本不做语义判断。**Agent 读文案、逐句标好，脚本才配得准。** 字面匹配在这套素材上已经验证失败（“我妈端盆接漏水”和任何 `desc` 都没有共同字符串），必须靠语义。

## 输出格式

```json
{
  "sentences": [
    {"i": 0, "text": "长假当天，我坐在楼下没漏水的地方。",
     "场景": "室内", "情绪": "冷清", "动作": "静止", "motion": "low"}
  ]
}
```

`i` 必须和 `mix.py` 切出来的句子序号严格一致。切句规则：按 `。！？；` 切，单句超 32 字再按 `，、` 切。

**最稳的做法**：先跑一次 `mix.py --no-voice --out 临时目录` 拿到 `sentences`，照着它的 `i` 和 `text` 填标签，再正式跑。这样序号绝不会错位。

## 词表（必须用原词，不许造）

素材库实际存在的值，造新词等于匹配不上。

| 维度 | 可选值 |
|---|---|
| **场景** | 户外 / 街道 / 车站 / 商场 / 集市 / 室内 / 田地 / 车内 / 车上 / 河边 / 餐厅 / 院子 / 厨房 / 楼道 |
| **情绪** | 日常 / 平淡 / 开阔 / 热闹 / 烟火气 / 忙碌 / 闲适 / 生活气息 / 冷清 / 平静 / 安静 / 随意 / 苍凉 / 轻松 / 荒凉 / 紧张 / 喜庆 |
| **动作** | 行走 / 静止 / 挑选 / 整理 / 付款 / 站立 / 观景 / 蹲坐 / 驾驶 / 跑动 / 聊天 / 运动 / 摇镜 |
| **人物** | 路人 / 本人 / 无 / 家人 / 老人 |
| **motion** | low / mid / high |

## 标注口径

**场景**——这句话讲的事发生在哪。讲屋里的事标 `室内`，讲赶路标 `街道` 或 `车站`，讲田地标 `田地`。
讲抽象道理、没有具体地点时，**留空**，别硬填。

**情绪**——这句话的情绪底色，不是事件本身。
「我妈一个人收拾了一地」→ `冷清` 或 `苍凉`，不是 `忙碌`。
「一屋子人围着桌子」→ `热闹` 或 `烟火气`。

**动作**——观众在这个画面上最该看到什么在发生。
抽象叙述可留空。宁可少标，不要乱标——标错的维度和不标一样有害。

**motion**——节奏。
句子在推进、有动作 → `high`；平静叙述 → `mid`；停顿、感慨、留白 → `low`。

**人物**——**建议一律留空**。
可公开池里 `家人` 只有 7 个、`老人` 1 个，标了也几乎筛不出东西，还会把评分分母撑大导致整体得分被稀释。B-roll 本来就不需要人物对应。

## 一条实用经验

混剪的 B-roll 是**氛围层**，不是**图解层**。讲「退掉六间房的订单」不需要拍到手机订单界面，拍到傍晚空荡的楼道、桌上的一杯凉水、窗外的雨就成立。

所以标注时问自己：**这段画面如果单独放着，能不能烘托这句话的气氛**，而不是「画面上有没有这句话说的东西」。

## 不要做的事

- 不要给每句都标满五个维度。标 2–3 个有把握的就够，留空不扣分。
- 不要为了「好看」把情绪都标成 `热闹` / `开阔`，那会让整片色调单一。
- 不要跨维度借词（`场景` 里填 `温暖` 之类）。
