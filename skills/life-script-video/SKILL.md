# 人生剧本视频

用户已认可此风格。制作前读取[固定开头与效果](references/approved-style.md)，保持其视觉和声音方向，不重新探索替代模板。工作台原四入口各六步不变；generate的preferences.style为life，选择只保存意向，不自动执行或授权费用。Agent按本Skill完成创作，通用工程/预算/原任务操作继续用随包92k-video-director。

先读实际项目、已选步骤和历史输出。优先复用已认可原片，不覆盖旧版。首次制作确定人物/故事设定、原创口述稿与分镜；故事靠具体生活细节和选择后果推进。虚构经历清楚标识，不能把示例作者自述当成自己的真实履历。

默认使用用户指定的“人生剧本音色”。接口尚待用户提供；现阶段导入用户已生成的完整配音。不要自动回退免费Edge男声，也不要把参考音频当作已经接通的TTS接口。接口到位后再核对服务协议、voice ID、计费及授权，凭据存本机私密配置，包内只留占位。已有成品声音不重新生成；仅样本而没有合成接口时先说明缺口。

保留一条连续旁白作为时间轴。实际转写/对齐词时码，字幕纠正同音错词/地名；配图按语义及停顿切换，约5秒只是起点。新音频替换后重对字幕/镜头，不机械按总时长拉伸。人物发型、服装、年龄与漫画风格一致，画面应对应地点/事件/情绪，可用同图不同推拉视角；保留生成提示词和素材来源。

按固定开头生成有力且可读的主题字，出生旁白到来时展示遮挡身份证式插图。后接正文，不重复旧动态片头或旧片头音效。优先使用已有用户配好的开场音频，文案不等于已授权冒充真实经历。

音乐为无人声纯音乐，随故事从艰难/低谷到转机/温暖或实际崛起分段；具体选择见固定效果。旁白侧链压低音乐，短促转场音不盖字。不得把温情故事硬改成战斗胜利音效。

输出新版本MP4、字幕、旁白/音乐/效果分轨、时码/镜头表与可复现编辑源。完整解码、检查音轨峰值/非静音、片头/身份证/换图/转折/结尾抽帧；没有实际听审就明确技术检查范围。用户明确认可后才记录该版本已认可。独立制作不冒称工作台自动执行或已登记成片，按当前工程真实支持的API登记，缺少适配先保留独立可播放交付。
