# 本地素材混剪（版本2）

> **版本说明**：本 skill 是从版本1（`footage-mix`）完整复制后独立改造而来，登记日期 2026-11-22。
> 相比版本1 只有两处改动（其余流程、约定、脚本完全一致）：
> 1. **转场默认 0.6s**（版本1 是 0.4s）
> 2. **每个长镜头轻微缓慢推近 1.0→1.04**（版本1 无推近）
>
> 版本1 完全不受影响，仍在 `E:\自媒体\skills\footage-mix\`。剪辑时按备注名选用：要新效果用本 skill，要原版用版本1。推近可随时用 `--no-zoom` 关掉。

## 用途

一段文案 + 本地素材库 → 一条横屏成片。画面按文案**大致匹配**，不追求严格对应。

素材库已 100% 打标（5567 个单元，11 维中文标签 + 画面描述），**不要靠文件名猜内容，也不要抽帧试看**——直接读 `desc` 和 `attr` 就够。

## 核心分工（先记住这条）

**语义判断归 Agent，确定性计算归脚本。**

脚本不会猜「我妈端盆接漏水」该配什么画面——字面匹配在这套素材上已经验证失败（和任何 `desc` 都没有共同字符串）。所以流程里有一道**人工/AI 标注**，必须在配音之前做。

## 五步流程

### 1. 先切句（不花钱）

```bash
cd "E:/自媒体/skills/footage-mix-v2"
python scripts/mix.py --script 文案.txt --out "项目目录" --dry-run
```

产出 `句子清单.txt`，带序号。**这个序号是后面所有对齐的基准**，不要自己数句。

### 2. Agent 逐句打标签 → `文案标签.json`

按 `references/tagging.md` 的受控词表标注。只标有把握的维度，留空不扣分。

```json
{"sentences": [
  {"i": 0, "text": "...", "场景": "室内", "情绪": "冷清", "motion": "low"}
]}
```

标完**把标注摘要给用户看一眼**，确认方向没错再往下——后面配音要花钱。

### 3. 配音（默认阿里云克隆音色）

```bash
python scripts/aliyun_tts.py --script 文案.txt --out "项目目录"
```

- **默认音色**：`cd105126e4254060a3ad75d70c8b374c`（「张琰华的音色」，阿里云百炼 / `qwen-audio-3.1-tts-flash`），走你本机的 **92K CLI**（`speech quote → create → status → result`）。
- **默认语速 = 音色自带**。用户已在音色里内置 1.2 倍速，**不要再做 atempo 变速**。
- 平台这条链路**只接受 `format=wav`**，传 mp3 会被 `request_failed` 拒掉；脚本内部转 mp3 落 `配音/NN.mp3`。
- 每块约 1 积分（438 字 / 5 块 ≈ 5 积分）。跑之前确认用户授权。
- 音色重建后 ID 会变，`speech voices --mine` 查最新 id，用 `--voice` 覆盖。

### 4. 算时间轴 + 配画面

```bash
python scripts/mix.py --script 文案.txt --tags 文案标签.json --out "项目目录" --privacy public
```

做的事：文案切块 → 读 `配音/*.mp3`（有缓存就直接用）→ 测实际时长 → 块内按字数分句对齐 → 每句按标签挑素材 → 写 `timeline.json`。

`mix.py` 本身内置了火山通道，但**默认流程不用它**——先用上一步的阿里云配音把 `配音/*.mp3` 生成好，这里就是缓存命中、不重复花钱。

**改了配音文件后必须删掉 `配音/*.wav`**：mp3→wav 那步有缓存，不清会继续用旧时长。

### 5. 看报告，再渲染

```bash
cat "项目目录/匹配报告.txt"
```

每句配了哪段、取原片第几秒、命中哪些标签。**这是唯一能在花渲染时间前发现「文不对画」的地方。**

```bash
# 默认就这一条：第 2 首背景音乐、音量默认（不做额外调整）
python scripts/render.py --project "项目目录" --bgm "E:/自媒体/背景音乐/2-安静的复苏.MP3"
python scripts/render.py --project "..." --no-subs      # 不要字幕
python scripts/render.py --project "..." --duck         # 旁白压 BGM（默认不压）
python scripts/render.py --project "..." --cpu          # NVENC 出问题时的退路
```

版本2 渲染默认就带 **0.6s 叠化 + 每镜轻微推近**，上面这条默认命令直接出新效果。想回到版本1 的观感：加 `--transition-duration 0.4 --no-zoom`。

**BGM 默认规范**：`E:\自媒体\背景音乐\2-安静的复苏.MP3`，**音量用默认值，不要加 `--bgm-volume`**。用户明确说过不用调。

## 参数速查

| 参数 | 作用 |
|---|---|
| `--privacy public` | **默认**，只用标「可公开」的 174 条原片 |
| `--privacy all` | 全部放开，含带娃/家人画面 |
| `--folders rural,food` | 限定题材：rural / kids / family / talk / city / scenery / food |
| `--max-shot 15` | 单个镜头最长秒数（硬上限，用户定一般别超 15s） |
| `--target-shot 6.5` | 目标镜头长度，短句往这个值合并 |
| `--soft-max 10` | 合并句子的软上限 |
| `--no-family` | 关闭画风一致性约束（默认开） |
| `--old-cut` | 回到旧的按句铺片（每句 1~2 个短片段），一般不用 |
| `--transition fade` | 转场：fade / dissolve / wipeleft / slideleft / circleopen / none |
| `--transition-duration 0.6` | 转场时长秒数（**版本2 默认 0.6**，版本1 是 0.4） |
| `--no-zoom`（版本2 新增） | 关闭缓慢推近；默认开，每镜 1.0→1.04 |
| `--zoom-to 1.04`（版本2 新增） | 推近终点倍率，默认 1.04，越大越明显 |
| `--no-voice` | 跳过配音，用 `配音/*.mp3` 里已有的 |
| `--voice <id>` | aliyun_tts.py 用，换克隆音色（音色重建后 ID 会变） |
| `--force` | aliyun_tts.py 用，已有配音也重做 |
| `--bgm-lufs -26` | BGM 响度基准，一般不用动 |
| `--bgm-volume 1.0` | **默认，不要改**（用户要求 BGM 音量保持默认） |

## 硬约束

1. **原片只读**：不剪切、不转码落盘、不移动、不改名、不删除。取片段一律 `-ss/-t` 现取。
2. **不留图**：素材库不产生任何缩略图/预览图/图片缓存。
3. **隐私开关要问**：默认 `public`。放开到 `all` 必须用户明确说过——227 条原片标了「家庭不宜公开」。
   ⚠️ 隐私是**打标时判的**，不是人工逐条核过的。要发出去的成片，建议用户抽查几条。
4. **配音要授权**：`mix.py` 会真调付费接口。
5. **不覆盖**：`--out` 目录已存在就换个名字，别把上一版盖掉。

## 色彩：HDR 必须转 SDR（已内置）

素材库 382 条是 **HEVC 10bit / HLG（arib-std-b67）真 HDR**，27 条 h264 是 SDR。`render.py` 逐片 `ffprobe` 查 `color_transfer`，只对 HDR 片段插 tonemap，SDR 原样过，输出统一打 bt709 标记。

不转的后果（实测过）：8bit 直接截断，黄色标线发白、绿色车漆寡淡，整片发灰；发到手机端还可能整体偏亮。

## 已知精度限制（如实告诉用户）

- **字幕时间**按块内字数比例估，与真实语音有 0.5–1 秒级偏差。要精确得装 `faster_whisper` 做词级对齐（当前环境没装）。
- **`desc` 偶尔和画面有出入**（打标是模型看图写的）。关键镜头建议渲染后抽帧看一眼。
- **可公开池里「家人」只有 7 个**，讲家庭故事时画面基本靠「场景 + 情绪」贴，不是靠人物对应。

## 出问题怎么查

| 症状 | 原因 | 处理 |
|---|---|---|
| 素材池是空的 | privacy/folders 过滤太狠 | 去掉 `--folders`，或改 `--privacy all` |
| 配音失败 | 工作台没起 / 令牌失效 | 跑 `check.py` 看那两行 |
| 时间轴不连续 | timeline.json 被手改过 | 重跑 `mix.py` |
| 整片画面雷同 | 素材池小 / 标签标得太集中 | 标签加维度，或放开 privacy |
| `asplit ... unconnected` | 滤镜链分支没用上 | 已在脚本里修，别再手改 filter |
| BGM 听不见 | BGM 本身太安静 | 调 `--bgm-lufs -20`，或加 `--duck` |
