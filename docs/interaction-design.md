# V2 交互设计

首页按输入分四类：已录口播、文案配真实素材、AI生成新画面、真人混搭资料。制作方式、项目、风格Skill、执行能力分层。

- 口播：导入→字幕粗剪→选风格→包装配乐→审看→交付。
- 素材解说：文案旁白→选风格→分镜需求→素材搜索选段→审看→交付。
- AI生成：脚本分镜→选能力→人物声音→模型预算→审看→交付。
- 真人混搭：真人与资料→字幕剪辑→选风格→资料映射→审看→交付。

全局库保留七项能力；口播保留自然口播、FredTalk、暗金、自由创意、资料讲解、网络素材解说六项。推荐与兼容非互斥。项目锁定风格版本、来源与采纳记录是后续目标，目前原型清单硬编码，尚无持久化版本管理。

项目顶部步骤、中间编辑、右侧方案、底部导航保持一致。素材卡应记录准确版本、原页面、发布者、许可、入出点及采纳；分镜映射人物、网络素材、生成镜头和说明动效。仅重做受影响片段。

草稿保存、确认方案、付费授权、素材采纳、成片认可应分别记录。费用未知显示待报价；未知原单只查原单，不自动重提。用户本地素材和配置不随源码更新。

当前原型只有页面内存状态、示例卡和导航，无真实执行；右侧9:16是展示值，不是实际输出参数。配置中心不接收真实Key。后续先统一项目持久化/注册目录，再接已有执行器，优先口播和素材解说，最后补生成、混搭、局部重做与异常恢复。
