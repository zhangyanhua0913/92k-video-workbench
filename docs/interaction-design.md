# V2 交互设计

2026-10-31用户固定要求：真实工作台必须恢复并保持原型四套六步的准确名称和顺序，不把已接后端改成技术控制台。任何未来页面步骤、顺序或主要交互改变，须先说明并取得明确确认。prototype.6恢复原侧栏/风格库/配置入口、步骤栏、右侧方案与底部导航；工程信息、恢复、重试及Agent接续默认收起。每步只展示相关编辑或审阅内容；切步先保存，失败停留原步。UI进度存在项目包外sidecar，不复制字幕、任务或预算账本。

首页按输入分四类：已录口播、文案配真实素材、AI生成新画面、真人混搭资料。制作方式、项目、风格Skill、执行能力分层。

- 口播：导入→字幕粗剪→选风格→包装配乐→审看→交付。
- 素材解说：文案旁白→选风格→分镜需求→素材搜索选段→审看→交付。
- AI生成：脚本分镜→选能力→人物声音→模型预算→审看→交付。
- 真人混搭：真人与资料→字幕剪辑→选风格→资料映射→审看→交付。

全局库保留七项能力；口播保留自然口播、FredTalk、暗金、自由创意、资料讲解、网络素材解说六项。推荐与兼容非互斥。项目锁定风格版本、来源与采纳记录是后续目标，目前原型清单硬编码，尚无持久化版本管理。

项目顶部步骤、中间编辑、右侧方案、底部导航保持一致。素材卡应记录准确版本、原页面、发布者、许可、入出点及采纳；分镜映射人物、网络素材、生成镜头和说明动效。仅重做受影响片段。

草稿保存、确认方案、付费授权、素材采纳、成片认可应分别记录。费用未知显示待报价；未知原单只查原单，不自动重提。用户本地素材和配置不随源码更新。

`preview`原型保持页面内存状态、示例卡和导航，无真实执行；右侧9:16是展示值，不是实际输出参数，配置中心不接收真实Key。

`open`新增真实工作台：四入口→创建/登记工程→工程进度、Agent接续与操作→同页编辑/审阅→真实输出。最近项目索引可重建，原字幕、预算与任务使用各自子工程数据库。口播/生成嵌入成熟编辑器；素材解说新增来源表和旁白时间轴；混搭支持资料片段映射与替换。原型与真实模式不共享示例确认或草稿。

状态按原项目与执行记录显示；普通草稿保存、预算授权、素材采纳、技术导出和最终认可仍分别记录。复杂包装及语义选段等待Agent，不伪造进度。真实素材解说当前输出固定16:9/720p；生成画幅以实际分镜设置为准，口播保持原素材比例。

口播和真人混搭的原“成片审看”“导出交付”步骤可显示与当前工程绑定的Agent独立审看片，标明待用户审看或历史版本并提供播放和下载。它不是内部render结果，原有内部成片确认按钮不对它生效；步骤名称及顺序不变。

口播的原“导出交付”步骤增加封面区域：显示当前风格、可选主题，保存后提示让Agent继续，可导入已制作图片并在本项目预览和下载。首种默认蓝黄人物观点风格通过独立Skill描述，注册表允许以后添加风格；不新增或改名六个步骤。封面方案与视频版本独立，不代表最终认可，也不自动唤醒Agent。
